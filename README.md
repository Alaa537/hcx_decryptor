# HCX Decryptor

Flutter Android application for analyzing/decrypting HTTP Custom `.hc` configuration files.

## Build environment

- Termux
- GitHub + GitHub Actions
- krinry CLI
- Flutter 3.41.0 on the cloud runner
- Java 17
- AGP 8.9.1
- Gradle 8.11.1
- Kotlin 2.1.0
- compileSdk 36
- targetSdk 36
- minSdk 24

The Android directory is generated by the GitHub Actions workflow with:

```bash
flutter create --platforms android .
```

No local Android/Gradle build is required.

## Files

The original Python implementation was ported into:

- `lib/services/hc_crypto.dart`
- `lib/services/hc_decryptor.dart`
- `lib/services/decrypt_service.dart`

The port preserves the source flow:

`outer envelope -> validation -> schedule/KDF -> XChaCha20-Poly1305 -> sections -> HPR1/HPC1 -> clean JSON`

## Cloud build

```bash
cd ~/hcx_decryptor
krinry flutter init
git init
git add .
git commit -m "init HCX Decryptor"
gh repo create hcx_decryptor --public --source=. --remote=origin --push
krinry flutter build apk --release
```

The workflow creates the Android project on the GitHub runner and uploads the resulting APK/AAB as `build-output`.
